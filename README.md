# Zero Core

Reusable Next.js application foundation for building structured business products without starting authentication, data access, UI infrastructure, and common application services from zero each time.

## What It Provides

- Next.js 14 + React 18 + TypeScript foundation
- Ant Design and Tailwind CSS UI stack
- Authentication and account flows with NextAuth
- MongoDB / Mongoose data layer
- Firebase and server-side Firebase integrations
- Reusable service, API, utility, and application structure
- File/media, messaging, email, realtime, and integration-ready dependencies
- Shared patterns intended to be adapted into larger products

## Stack

Next.js, React, TypeScript, Ant Design, Tailwind CSS, MongoDB, Mongoose, NextAuth, Firebase, SWR, Axios, Pusher and Framer Motion.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

## Purpose

Zero Core is maintained as a reusable project template/foundation rather than a finished end-user product. Individual applications built from it can replace or remove the modules they do not need.
